\textbf{\underline{Theorem 11.1 - The Remainder Theorem}}

\par\textbf{\underline{Lemma 11.2 }}

\par\textbf{\underline{Lemma 11.3 -Linear Combination Lemma }}
Let a, b, and d be integers. If d divides both
a and b, then d divides every integer linear combination of a and b. In other words, for
every pair of integers m, n $\in$ Z, the integer d also divides ma + nb.
\par\textbf{\underline{Theorem 11.4 -Bezout's Identity}}
Let a and b be integers. Then gcd(a, b) is an integer
linear combination of a and b. That is, there are integers s and t such that gcd(a, b) =
sa + tb.
\par\textbf{\underline{Corollary 11.5 }}
Let a, b, c $\in$ Z. Suppose c $\neq$ 0, c divides ab and gcd(a, c) = 1. Then c
divides b.
\par\textbf{\underline{Corollary 11.6 }}
Let a, b $\in$ Z and let d $\in$ Z be such that d divides a and d divides b. Then d
divides gcd(a, b).
\par\textbf{\underline{Corollary 11.7}}
Let d be a common divisor of a and b, which is divisible by all divisors
of a and b. Then d = \underbar{+}gcd(a, b).
\par\textbf{\underline{Corollary 11.8}}
If a, b $\in$ Z, p is prime, and p divides ab, then either p divides a or p divides
b (or both).

\textbf{\underline{Theorem 12.1}}
Let m $\in$ N and a,b $\in$ Z. The following are equivalent:
(1) a =b mod m; (2) m divides a - b; (3) a and b have same remainder when divided by m; (4) b = qm + a for some q $\in$ Z.
\par\textbf{\underline{Theorem 12.2}}
We have the following properties for integers a, b, c $\in$ Z and m $\in$ N:
(1) a = a mod m;(2) If a = b mod m, then b = a mod m. (3) If a = b mod m and b = c mod m, then a = c mod m.
\par\textbf{\underline{Theorem 12.3}}
Suppose a = x mod m and b = y mod m. Then
(1) -a = -x mod m; (2) a + b = x + y mod m; (3) ab = xy mod m; (4) or any natural number k, one has a$^k$ = x$^k$ mod m.
\par\textbf{\underline{Theorem 12.4}}
Let a and m be coprime. If x, y $\in$ Z and xa = ya mod m, then x = y
mod m. In particular, if p is prime and p does not divide a, then xa = ya mod p implies
that x = y mod p.
\par\textbf{\underline{Theorem 12.5}}

b.

\par\textbf{\underline{\textit{Week 8:}}}
\textbf{\underline{Theorem 13.1 }}
Let f : X $\rightarrow$ Y and g : Y $\rightarrow$ Z be functions.
(1) If f and g are injective, so is g $\circ$ f. (2)  If f and g are surjective, so is g $\circ$ f. (3) If f and g are bijective, so is g $\circ$ f.
\par\textbf{\underline{Theorem 13.2 }}
Let f : X $\rightarrow$ Y be a function and B, B$^\prime$ $\subseteq$ Y. Then
f$^{-1}$(B $\cap$ B$^\prime$) = f$^{-1}$(B) $\cap$ f$^{-1}$(B$^\prime$) and f$^{-1}$(B $\cup$ B$^\prime$) = f$^{-1}$(B) $\cup$ f$^{-1}$(B$^\prime$)
\par\textbf{\underline{Theorem 13.3 }}
Let X and Y be finite sets and let f : X $\rightarrow$ Y be a function.
(1) If f is injective, then $|\mbox{X}|$ $\leq$ $|\mbox{Y}|$. (2) If f is surjective, then $|\mbox{X}|$ $\geq$ $|\mbox{Y}|$. (3)  If f is bijective, then $|\mbox{X}|$ = $|\mbox{Y}|$.

\par\textbf{\underline{\textit{Week 9:}}}
\textbf{\underline{Theorem 15.1 -Multiplication Principle }}
Let P be a process consisting of n stages such
that at each stage i, there are a$_i$ choices we can make, and no two distinct choices
can result in the same outcome. Then after n stages, the total number of outcomes is
a$_1 · \mbox{a}_2 \dots \mbox{a}_n$.
\par\textbf{\underline{Theorem 15.3 -Ordering Theorem }}
Given a set S of n distinct objects, there are n! ways
of ordering them.
\par\textbf{\underline{Theorem 15.5}}
For integers 0 $\leq$ k $\leq$ n, we have
$\left( \begin{array}{c} n \\ k \end{array} \right)$ = $\frac{\mbox{n}!}{\mbox{k!(n-k)!}}$
\par\textbf{\underline{Corollary 15.6}}
For n $\geq$ 0, we have
2$^n$= $\sum_{k=0}^{n}$ $\left( \begin{array}{c} n \\ k \end{array} \right)$
