\textbf{\underline{Theorem 7.1 Monotone Convergence Theorem}}
Let (a$_n$) be an increasing
sequence of real numbers that is bounded above (i.e. there is M so that a$_n$ $\leq$ M for all
n). Then (a$_n$) converges to some limit. If (a$_n$) is a decreasing sequence and is bounded
below, then (a$_n$) converges to some limit.
